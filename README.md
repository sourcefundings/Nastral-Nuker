# Nastral-Nuker-Advanced-Discord-Nuker-made-in-Python
Nastral Nuker is an advanced Discord Nuker made in Python. Using threads able to reach speeds that you can reach with any node application.

# BEFORE USING

Make sure you install the required libraries using the **install.bat** file. 
The program will automatically run after you ran install.

# How to use

- Run **launch.bat** and wait a few seconds.
- Enter your Discord Bot token.
- Select the Discord Server of your choice, copy the id and paste it.
- Fill out the required information

**IMPORTANT NOTICE**
- The ban all feature does NOT work. 
- When prompted just select **no** and put random stuff in the following prompts.
